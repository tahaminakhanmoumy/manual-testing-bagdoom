# Bagdoom Web Application – Manual Testing Project

## 📌 Project Overview

This repository contains the manual testing documentation for the Bagdoom web application.

The primary focus of this project was to test the **Registration / Sign Up** functionality and identify functional issues through systematic manual testing.

## 🎯 Testing Scope

### Module Tested
- Registration
- Sign Up / Create Account

### Test Environment
- Operating System: Windows 10
- Browser: Google Chrome
- Testing Type: Manual Testing

## 🧪 Testing Activities

The following testing activities were performed as part of this project:

- Test Planning
- Requirement/Feature Analysis
- Mind Mapping
- Test Scenario Design
- Test Case Design
- Test Case Execution
- Bug Identification and Reporting
- Test Case Reporting
- Test Metrics Analysis

## 📂 Project Documents

This repository contains the following testing documents:

| Document | Description |
|---|---|
| Test Plan | Defines the testing scope, environment, objectives, and approach |
| Mind Map | Visual representation of the testing areas |
| Test Scenarios | High-level scenarios for the Registration module |
| Test Cases | Detailed test cases with expected and actual results |
| Bug Report | Documented defects with reproduction steps, severity, and priority |
| Test Case Report | Summary of test case execution |
| Test Matrix | Test execution and testing metrics |

## 📊 Test Execution Summary

A total of **17 test cases** were documented for the Registration module.

- Passed: 12
- Failed: 5
- Not Executed: 0
- Blocked: 0

The failed test cases were documented with relevant details in the Bug Report.
